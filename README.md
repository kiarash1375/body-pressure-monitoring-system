# Body Pressure Monitoring System (BPMS)

## Overview

Software platform developed for pressure monitoring applications used in medical anti-bedsore systems.

The system collects, processes, and visualizes pressure data in real time to support patient care and monitoring.

---

## Responsibilities

- Developed software modules
- Integrated pressure sensing hardware
- Implemented calibration workflows
- Performed testing and validation
- Processed sensor data for analysis
